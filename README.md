# Home Hunter

Личный мониторинг квартир на Django и PostgreSQL. Источники: Avito, CIAN и Домклик. Приложение сохраняет историю цен и карточек, показывает объявления на карте, поддерживает личные оценки, сравнение с рынком, XLSX-выгрузки и Telegram-уведомления.

Интерфейс построен на Django templates; сбор и фоновые задачи выполняются management-командами. В проекте нет Celery, Redis и отдельной frontend-сборки.

Настройки окружения перечислены в [.env.example](.env.example). Для локального запуска нужны Python 3.12 и PostgreSQL 17; PostgreSQL можно поднять через Docker Compose. Подробная последовательность находится в инструкции разработки.

Fast scan сохраняет найденное и не деактивирует отсутствующие объявления. Полный проход может изменять активность только после проверок полноты. Ошибки и частичные проходы не должны удалять историю или снимать объявления с активности.

Исторические отчёты и исходное техническое задание перечислены отдельно в каталоге документов: они не описывают состояние действующего сервера.
